# DaktiloJS

DaktiloJS is a lightweight and customizable JavaScript library for simulating typewriter-like text animations on web pages. It supports various features, including customizable typing speeds, sound effects, adaptive volume based on distance, and loopable animations.

## Features

- **Typing and Deleting Animations**: Smooth and realistic simulation of typing and deleting text.
- **Cursor Customization**: Blinking cursor with adjustable character and blink duration.
- **Sound Effects**: Optional typing and carriage return sounds with customizable volume.
- **Adaptive Sound**: Adjusts volume based on the distance between the element and the viewport center.
- **Loops and Delays**: Loop animations and set delays between actions.
- **Debugging**: Built-in debugging logs for troubleshooting.
- **CSS Injection**: Automatically injects required styles.
